Существуют 2 вида бд: 
SQL(реляционные) - Данные хранятся в таблицах со строками и столбцами. Таблицы связаны между собой.
NOSQL(нереляционные) - Данные хранятся в других форматах — документы, ключ-значение, графы и т.д.

SQL (Structured Query Language) — язык для работы с реляционными БД.
