## Типы данных
Типы Go делятся на четыре категории: фундаментальные типы, составные (агрегированные) типы, ссылочные типы и типы интерфейсов. 
### Целые числа

```go
var i int = 42

// Знаковые (могут быть отрицательными)
var i8  int8  = 127          // от -128 до 127
var i16 int16 = 32767        // от -32768 до 32767
var i32 int32 = 2147483647   // от -2млрд до 2млрд
var i64 int64 = 9223372036854775807

// Беззнаковые (только положительные)
var u8  uint8  = 255         // от 0 до 255
var u16 uint16 = 65535
var u32 uint32 = 4294967295
var u64 uint64 = 18446744073709551615
```
> По умолчанию используй `int` — Go сам выберет оптимальный размер под платформу.
Тип rune является синонимом для типа int32 и по соглашению указывает, что данное значение является символом Unicode.
Аналогично тип byte является синонимом для типа uint8 и подчеркивает, что это значение является фрагментом неформатированных данных, а не малым числом.

### Числа с плавающей запятой

```go
var f32 float32 = 3.14    // ~6-7 значимых цифр
var f64 float64 = 3.14    // ~15-16 значимых цифр
```
> `float64` используй всегда — `float32` только если критична память.

### Строки и символы

```go
var s string = "Привет, мир!"  // строка в UTF-8, неизменяемая
var b byte = 'A'               // 65 byte = uint8 — один байт ASCII
var r rune = 'Я'               // 1071 rune = int32 — один Unicode-символ
len("Привет")           // 12 — байты, не символы!
len([]rune("Привет"))   // 6 — символы
```
>Функция len() выводит число символов, в случае с кириллицой и эмодзи, она выводит байты, поэтому нужно приводить конструкцией len([]rune("Привет"))

### Булевый тип

```go
var t bool = true
var f bool = false
```

### Нулевые значения (zero values)

Переменные без инициализации получают нулевое значение — не `nil` и не мусор.

| Тип                                       | Нулевое значение |
|-------------------------------------------|-----------------|
| `int`, `float64`                          | `0`             |
| `string`                                  | `""`            |
| `bool`                                    | `false`         |
| pointer, slice, map, channel, interface   | `nil`           |
Нулевое значение составного типа наподобие массивов или структур представляет собой нулевые значения всех его элементов или полей.

### Преобразование типов

Go не делает неявных преобразований — всё вручную:

```go
var i int = 42
var f float64 = float64(i)    // int → float64
var u uint = uint(f)          // float64 → uint

s := strconv.Itoa(i)          // int → string
n, _ := strconv.Atoi("42")    // string → int (может вернуть ошибку)
```

### Краткое объявление

```go
x := 42           // тип выводится автоматически (int)
y := 3.14         // float64
z := "hello"      // string
a, b := 1, 2      // несколько переменных сразу
```

### Константы

```go
const pi float64 = 3.14
const pi, e = 3.1415, 2.7182
const (
  pi float64 = 3.1415
  e float64 = 2.7182
)
```
>Если у константы не указан тип, то он выводится неявно на основании того значения, которым инициализируется константа
>iota — автоматический счётчик, который начинается с 0 и увеличивается на 1 для каждой константы в блоке.

## Области видимости (Scope)

Есть две области видимости: уровень пакета и уровень функции/блока
Переменная уровня пакета доступна во всех файлах без импорта
Переменная уровня блока доступна только внутри ```{}```
Вложенный блок **видит** всё из внешнего, но не наоборот. Работает для `if`, `for`, `switch`, `func`.
Экспортируемые переменные именуются с заглавной буквы, приватные со строчной
```go
var Public = "виден снаружи"   // ✅ доступна из других пакетов
var private = "только внутри"  // ❌ снаружи не видна
```
Нельзя обратиться к переменной до её объявления
Можно объявить переменную с тем же именем во вложенном блоке — она перекроет внешнюю(Shadowing)
Переменные уровня пакета инициализируются до начала выполнения функции main
Локальные переменные инициализируются тогда, когда в процессе выполнения функции встречаются их объявления.
Краткое объявление переменной действует как присваивание только для переменных, которые уже были объявлены в том же лексическом блоке; объявления во внешнем блоке игнорируются. 

## Указатели

Указатель — это переменная, которая хранит адрес памяти другой переменной, а не само значение.
```go
var x int = 42
var p *int = &x
```
>&x — взять адрес переменной x
>*p — получить значение по адресу (разыменование)
>new(int) — возвращает указатель *int, а var x int — обычную переменную

## Инициализация
Любой файл может содержать любое количество функций, объявление которых имеет вид func init() {/*...*/}
Такие функции нельзя вызвать или обратиться к ним, но во всех прочих отношениях они являются нормальными функциями. 
В каждом файле функции init выполняются автоматически при запуске программы в том порядке, в котором они объявлены.

Порядок всего при запуске программы
1. Инициализируются пакеты-зависимости (снизу вверх)
2. Инициализируются переменные уровня пакета
3. Выполняются функции init() в порядке объявления
4. Запускается main()

# Составные типы: массивы, срезы, append

## Массивы

**Массив** — последовательность **фиксированной длины** из элементов **одного типа**. Размер задаётся раз и навсегда.

### Доступ и перебор

Индексация от `0` до `len-1`. `len` возвращает количество элементов.

```go
var a [3]int             // массив из трёх целых
fmt.Println(a[0])        // первый элемент
fmt.Println(a[len(a)-1]) // последний, то есть a[2]

// индекс + значение
for i, v := range a {
    fmt.Printf("%d %d\n", i, v)
}

// только значения — нужен пустой идентификатор _
for _, v := range a {
    fmt.Printf("%d\n", v)
}
```
Без инициализации все элементы = нулевое значение типа (для чисел `0`).

```go
// ... вместо длины: размер по числу инициализаторов
q := [...]int{1, 2, 3}
fmt.Printf("%T\n", q) // "[3]int"

// пары "индекс: значение" в любом порядке, пропуски = ноль
symbol := [...]string{USD: "$", EUR: "€", GBP: "£", RUR: "₽"}
fmt.Println(RUR, symbol[RUR]) // "3 ₽"

// разреженный массив: 100 элементов (0..99), ненулевой только последний
r := [...]int{99: -1}
```

`[3]int` и `[4]int` — **разные типы**. Размер обязан быть константой времени компиляции.

### Сравнение

Если тип элемента сравниваемый — массив тоже сравниваем через `==` (поэлементно). Разные размеры = разные типы → сравнить нельзя (ошибка компиляции, не `false`).

```go
a := [2]int{1, 2}
b := [...]int{1, 2}
c := [2]int{1, 3}
fmt.Println(a == b, a == c, b == c) // "true false false"

d := [3]int{1, 2}
fmt.Println(a == d) // ошибка компиляции: разные типы
```

### Передача по значению

Массив **копируется** при передаче в функцию:
- передача большого массива неэффективна (копируется целиком);
- изменения внутри функции затрагивают только копию, оригинал не меняется.

Чтобы менять оригинал — передавай **указатель**:

```go
func zero(ptr *[32]byte) {
    *ptr = [32]byte{} // обнуляем весь массив
}
```

Но даже указатель не снимает главного ограничения: `*[32]byte` не примет `*[16]byte`, добавлять/удалять элементы нельзя. Уместный случай фиксированного размера — `[32]byte` для хеша SHA256.

## Срезы

**Срез (slice)** — последовательность элементов одного типа **переменной длины**. Тип: `[]T` — как массив, но без размера в скобках.

Ключевая идея: срез — не хранилище, а лёгкая структура-**«окошко»**, смотрящая на *базовый массив* (backing array), где реально лежат данные.

### Три компонента среза

| Поле | Что значит |
|------|-----------|
| **Указатель** | на первый видимый через срез элемент массива (не обязательно самый первый элемент массива) |
| **Длина** `len` | сколько элементов сейчас в срезе |
| **Ёмкость** `cap` | сколько помещается от начала среза до конца базового массива |

Длина не может превышать ёмкость. Значения — через `len` и `cap`.
Несколько срезов могут смотреть на один массив, в т.ч. на **перекрывающиеся** части:

### Оператор среза s[i:j]

Создаёт **новый срез** на элементы с `i` по `j-1` (всего `j - i`):
- опустить `i` → `0`;
- опустить `j` → `len(s)`;
- источник: массив, указатель на массив или другой срез.

**Границы:**
- срезание за пределы `cap` → **паника**;
- срезание за пределы `len`, но в пределах `cap` → допустимо, **расширяет** срез.

```go
fmt.Println(summer[:20])    // паника: выход за границы
endlessSummer := summer[:5] // расширение в пределах cap — ОК
// "[Июнь Июль Август Сентябрь Октябрь]"
```

### Срез — это псевдоним (alias)

Передача среза в функцию даёт доступ к тому же базовому массиву → функция может менять оригинал. Копирование среза копирует только тройку (ptr/len/cap), а не данные.

```go
// reverse — разворот "на месте", без доп. памяти
func reverse(s []int) {
    for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
        s[i], s[j] = s[j], s[i]
    }
}

a := [...]int{0, 1, 2, 3, 4, 5}
reverse(a[:]) // массив → срез через a[:]
fmt.Println(a) // "[5 4 3 2 1 0]"
```

**Литерал среза** `[]int{...}` неявно создаёт безымянный массив нужного размера + срез на него. Отличие от `[...]int{...}` (массив) — отсутствие размера.

### Сравнение запрещено

Срезы **нельзя** сравнивать через `==` (кроме сравнения с `nil`). Причины:
1. элементы косвенные → срез может содержать сам себя; корректное сравнение не выходит простым/очевидным;
2. содержимое меняется во времени (зависит от базового массива), а ключи `map` должны иметь неизменное равенство → срезы не годятся в ключи.
```go
var s []int        // len==0, s == nil
s = []int{}        // len==0, s != nil   ← НЕ nil!
make([]int, 3)[3:] // len==0, != nil
```

→ Пустоту проверяй через `len(s) == 0`, **не** через `s == nil`.
`reverse(nil)` безопасен; все срезы нулевой длины функции должны обрабатывать одинаково.

### make

```go
make([]T, len)
make([]T, len, cap) // если cap опущен, cap = len
```
Создаёт безымянный массив и возвращает срез на него. Если `cap > len`, запас (от `len` до `cap`) зарезервирован для будущего роста.

```go
var runes []rune
for _, r := range "Hello, 世界" {
    runes = append(runes, r)
}
// результат присваивается обратно той же переменной — это критично
```
**Два сценария:**
1. `zlen <= cap(x)` — ёмкости хватает: расширяем срез в том же массиве. `x` и `z` делят базовый массив.
2. `else` — ёмкости нет: выделяем новый массив, копируем всё через `copy`, дописываем. `z` смотрит на **другой** массив.

`copy(dst, src)` копирует элементы из одного среза в другой того же типа. Порядок как в `dst = src`. Срезы могут перекрываться. Возвращает число скопированных = меньшая из длин → за границы выйти нельзя.

- **i=3:** `[0 1 2]`, cap=4 → есть место, добавляем без выделения, тот же массив.
- **i=4:** len=cap=4 → новый массив на 8, copy `[0 1 2 3]`, дописываем 4. Массивы разные.

Заранее **неизвестно**, переедет срез или нет. Поэтому результат всегда присваивай обратно:

```go
s = append(s, ...)
```

Это касается любой функции, меняющей длину/ёмкость/базовый массив среза.
`append` возвращает новое значение этой структуры — не присвоишь обратно, обновление ptr/len/cap потеряется. Отсюда обязательность `s = append(...)`.

### Вариадичность — две роли троеточия

```go
func appendInt(x []int, y ...int) []int {...} // объявление: любое число аргументов
x = append(x, x...)                            // вызов: разворачивает срез в аргументы
// "[1 2 3 4 5 6 1 2 3 4 5 6]"
```
