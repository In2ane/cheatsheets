## CLI

### Запуск и сборка

```bash
go run main.go              # запустить без компиляции в файл
go run .                    # запустить пакет в текущей папке
go build .                  # собрать бинарник в текущую папку
go build -o app .           # собрать с именем app
go install .                # собрать и положить в $GOPATH/bin
```

### Тесты

```bash
go test ./...               # запустить все тесты
go test ./... -v            # с подробным выводом
go test ./... -run TestName # только конкретный тест
go test -cover ./...        # с покрытием
go test -bench=. ./...      # бенчмарки
```

### Качество кода

```bash
go fmt ./...                # форматировать весь код
go vet ./...                # статический анализ (ловит баги)
go doc fmt.Println          # документация по функции
go doc encoding/json        # документация по пакету
```

### Окружение

```bash
go env                      # все переменные окружения Go
go env GOPATH               # конкретная переменная
go version                  # версия Go
```

### go mod — менеджер зависимостей

```bash
go mod init       # название/ссылка на репозиторий - инициализирует модуль
go mod tidy       # смотрит проект и устанавливает используемые пакеты и удаляет неиспользуемые из go.mod
go mod download   # скачать все зависимости из go.mod (без сборки) CI/CD, хочешь скачать отдельно от сборки
go mod verify     # проверить контрольные суммы (go.sum) CI/CD, проверка безопасности перед деплоем
go mod vendor     # скопировать зависимости в папку vendor/ нет интернета на сервере, корпоративные ограничения
```

```bash
go get github.com/gin-gonic/gin          # установить последнюю версию
go get github.com/gin-gonic/gin@v1.9.1   # конкретная версию
go get github.com/gin-gonic/gin@latest   # явно последнюю
go get github.com/gin-gonic/gin@none     # удалить пакет
```

| Файл       | Аналог              | Коммитить? |
|------------|---------------------|------------|
| `go.mod`   | `package.json`      | Да         |
| `go.sum`   | `package-lock.json` | Да         |
