# Структуры

Структура — это составной тип данных, который группирует поля разных типов под одним именем.
Что то типо класса, позволяет обьявить существующие свойства и создавать экземпляры.

```go
// Встраивание
type Test struct {Name string}
type Test1 struct {Age int}
type Test2 struct {
	Test
	Test1
}

// Способы создания экземпляра:
var test Test // экземпляр структуры с пустыми значениями
test := Test{Name: "Test"} // литеральное обьявление
test := Test{"Test"} // сокращенное литеральное обьявление по порядку полей
test := new(Test) // *Test
test := &Test{Name: "Test"}   // *Test, используется чаще, чем new() т.к. позволяет сразу проинициализировать поля

// Создание метода
func (t Test) Method() {} // Получатель-значение — работает с копией
func (t *Test) Method() {} // Получатель-указатель — может менять оригинал
```

## Теги структур

Метаданные полей в обратных кавычках. Читаются библиотеками через рефлексию.
Формат: `ключ:"значение"`, можно несколько через пробел.

type User struct {
    Name     string `json:"name"`            // имя ключа в JSON
    Email    string `json:"email,omitempty"` // пропустить, если пусто
    Password string `json:"-"`               // не сериализовать
}

- omitempty — не включать пустое значение (0, "", nil)
- "-"       — полностью исключить поле
- Работают ТОЛЬКО с экспортируемыми полями (с большой буквы)
- Частые адресаты: json, xml, db (ORM), validate

## ТЗ: модуль обработки заказов

Цель: реализовать пакет `order` с моделями данных и бизнес-логикой создания заказа. Код должен компилироваться и проходить тесты.

### Модели

| Структура | Поля | Требования |
|---|---|---|
| `Model` | `ID int64`, `CreatedAt time.Time` | базовая, встраивается в остальные |
| `Item` | `SKU string`, `Qty int`, `PriceCents int` | позиция заказа |
| `Customer` | встраивает `Model`; `Name`, `Email string` | клиент |
| `Order` | встраивает `Model`; `Customer Customer`; `Items []Item`; `Total int`; `PromoCode string`; `internalID string` | заказ |

### Требования к JSON-тегам

- `ID` → `id`, `CreatedAt` → `created_at`
- `Customer.Name` → `name`, `Customer.Email` → `email`
- `Order.Total` → `total_cents`
- `Order.PromoCode` → `promo_code`, **опускать если пусто**
- `Order.internalID` → **не сериализуется**
- `Customer` — именованное поле (`json:"customer"`), не встраивание

### Функции и методы

```go
// Конструктор. Возвращает *Order с CreatedAt = текущее время.
func NewOrder(c Customer, items []Item) *Order

// Read-only: сумма всех позиций (Qty * PriceCents). Оригинал не меняет.
func (o Order) CalcTotal() int

// Read-only: форматированный чек строкой.
func (o Order) Receipt() string

// Мутирует Total. Поддержать промокоды:
//   "SALE10" → -10%, "SALE20" → -20%.
// Неизвестный код → вернуть error, Total не трогать.
func (o *Order) ApplyPromo(code string) error

// Нормализация и проверка перед сохранением:
//   - Items не пуст (иначе error)
//   - Email содержит "@" (иначе error)
//   - выставить o.Total = o.CalcTotal(), если Total == 0
func (o *Order) Validate() error
```

### Правила

1. Методы, изменяющие состояние (`ApplyPromo`, `Validate`), — только на указателе `*Order`.
2. Read-only методы (`CalcTotal`, `Receipt`) — на значении.
3. Все методы типа держать с одинаковым видом получателя (если есть указательные — все указательные).

### Сценарий-проверка (`main` или тест)

```go
items := []Item{...}              // сокращённый литерал
order := NewOrder(customer, items) // конструктор → &Order{}
order.Validate()                   // выставит Total
order.ApplyPromo("SALE10")         // Total уменьшится на 10%
fmt.Println(order.Receipt())       // read-only вывод
data, _ := json.Marshal(order)     // нет internalID, promo_code есть, ключи snake_case
```

### Критерии приёмки

- [ ] `json.Marshal(order)` не содержит `internalID`
- [ ] при пустом `PromoCode` ключ `promo_code` отсутствует в JSON
- [ ] `ApplyPromo` с неизвестным кодом возвращает ошибку и не меняет `Total`
- [ ] `Validate` на пустых `Items` возвращает ошибку
- [ ] `order.ID` и `order.CreatedAt` доступны напрямую (работает встраивание `Model`)
