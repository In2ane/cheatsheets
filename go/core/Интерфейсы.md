## Тип vs Интерфейс

`type` — ключевое слово «объявляю новый тип». И структура, и интерфейс объявляются через `type`:
```go
type Person struct { Name string }   // тип-данные
type Speaker interface { Speak() }    // тип-поведение
```
- **struct** — описывает ДАННЫЕ (поля). Методы объявляются снаружи, но принадлежат типу.
- **interface** — описывает ПОВЕДЕНИЕ (сигнатуры методов). Не содержит методы, а ТРЕБУЕТ их наличие.
- Интерфейс — частный случай типа, а не альтернатива ему (в отличие от TS).

## Переписываем JS-класс на Go

Класс = одна структура (поля) + методы на ней. Интерфейс НЕ нужен.
```go
type Counter struct { count int }
func (c *Counter) Increment() { c.count++ }   // методы живут на структуре
func (c Counter) Value() int  { return c.count }
```
Интерфейс добавляй ТОЛЬКО когда:
- несколько типов надо обрабатывать одинаково (общий список/параметр)
- нужно подменять реализацию (прод vs тест-мок)
- функция принимает «что угодно, лишь бы умело X»

Правило Go: интерфейс вводят когда понадобился, а не заранее.
