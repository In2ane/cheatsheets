## Роадмап

### Основы языка

- ✅ Переменные, краткое объявление, константы, `iota`
- ✅ Типы данных и преобразования
- ✅ Области видимости, shadowing
- ✅ Указатели, `new` vs `var`
- ✅ `init()` и порядок инициализации программы
- ✅ Массивы
- ✅ Срезы: len/cap/указатель, aliasing, `make`, `append`
- ✅ Структуры и теги структур
- 🟡 Строки, руны, `byte`, работа с UTF-8
- 🟡 Методы: value vs pointer receiver, встраивание
- 🟡 Интерфейсы: пустой интерфейс, type assertion, type switch
- ⬜ `map`: устройство, итерация, отсутствие порядка
- ⬜ Функции: замыкания, `defer`, множественный возврат
- ⬜ Ошибки: `error`, `errors.Is/As`, обёртывание `%w`, кастомные ошибки
- ⬜ `panic` / `recover`
- ⬜ Дженерики: type parameters, constraints

### Конкурентность 🎯 следующий крупный блок

- ⬜ Горутины: запуск, стоимость, утечки
- ⬜ Каналы: буферизованные/небуферизованные, закрытие, `range`
- ⬜ `select`, таймауты, `time.After`
- ⬜ `sync`: `Mutex`, `RWMutex`, `WaitGroup`, `Once`, `atomic`
- ⬜ `context`: отмена, дедлайны, передача значений
- ⬜ Паттерны: worker pool, fan-in/fan-out, pipeline, semaphore
- ⬜ Race detector, гонки данных, happens-before

### Стандартная библиотека

- ✅ `fmt`
- 🟡 `encoding/json` — теги знаю, marshal/unmarshal и edge-кейсы нет
- ⬜ `strings`, `strconv`, `bytes`
- ⬜ `time`
- ⬜ `os`, `io`, `bufio`
- ⬜ `net/http`: сервер, клиент, middleware, `ServeMux`
- ⬜ `database/sql`: соединения, пул, `sqlx`/`pgx`
- ⬜ `sort`, `slices`, `maps`

### Инструменты

- ✅ `go mod` — менеджер зависимостей
- ✅ `go build` / `go run`, кросс-компиляция
- 🟡 Тестирование: `testing`, table-driven тесты
- 🟡 `gofmt`, `go vet`, линтеры
- ⬜ Бенчмарки, `pprof`, профилирование

### Практика

- 🟡 Алгоритмические задачи (контест Т-Банка разобран)
- ⬜ REST API сервис с нуля
- ⬜ Работа с PostgreSQL из Go
- ⬜ Структура проекта, слои, внедрение зависимостей
- ⬜ Graceful shutdown, конфигурация, логирование
