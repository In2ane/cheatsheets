# Тема 0, практика 1. MAC и IP своими глазами (Windows)

> Учебный материал, выданный Claude. Дата: 2026-10-16.
> Повод: в задаче 1 не сложилось, почему MAC меняется на каждом хопе, а IP нет. Проверяем на своей машине.

## Цель

Увидеть: пакет в интернет уходит с **MAC роутера** в поле «кому», но с **IP конечного сервера**.

## Шаг 1. Свои адреса и шлюз

```powershell
ipconfig /all
```
У активного адаптера (Wi-Fi или Ethernet) записать:
- `Физический адрес` / `Physical Address` — твой MAC;
- `IPv4-адрес` — твой IP;
- `Основной шлюз` / `Default Gateway` — IP роутера (обычно `192.168.0.1` или `192.168.1.1`).

## Шаг 2. MAC роутера

```powershell
arp -a
```
Найти строку с IP шлюза — рядом его MAC. Это единственный «сосед», через которого ноутбук ходит в интернет.

## Шаг 3. Поймать пакет

Вариант А — Wireshark (wireshark.org): выбрать активный интерфейс, в фильтр вписать `icmp`, запустить захват. В PowerShell:
```powershell
ping -n 2 8.8.8.8
ping -n 2 1.1.1.1
```
Остановить захват, открыть любой Echo (ping) request, развернуть `Ethernet II` и `Internet Protocol`.

Вариант Б — без установки, встроенный `pktmon` (PowerShell от администратора):
```powershell
pktmon filter add -i 8.8.8.8
pktmon start --capture
ping -n 2 8.8.8.8
pktmon stop
pktmon etl2txt PktMon.etl
pktmon filter remove
```
Открыть `PktMon.txt`, в строках с ICMP искать пары MAC (`xx-xx-xx-xx-xx-xx > yy-yy-...`) и IP.

## Что должно получиться

| Поле | Пинг 8.8.8.8 | Пинг 1.1.1.1 |
|---|---|---|
| src MAC | твой MAC | твой MAC |
| dst MAC | **MAC роутера** | **MAC роутера — тот же** |
| src IP | твой IP | твой IP |
| dst IP | 8.8.8.8 | 1.1.1.1 |

Два разных сервера в разных концах мира, а dst MAC одинаковый: это роутер, ближайший сосед.
MAC отвечает на вопрос «кому отдать прямо сейчас», IP — «куда в итоге».

## Шаг 4. Хопы

```powershell
tracert 8.8.8.8
```
Каждая строка — маршрутизатор, на котором кадр разобрали и собрали заново с новыми MAC. IP назначения во всех этих кадрах — `8.8.8.8`.
