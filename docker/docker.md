npm install

Устанавливает зависимости и обновляет package-lock.json если есть расхождения с package.json
Если node_modules уже есть — доустанавливает только недостающее
Непредсказуем: два запуска могут дать разный результат

npm ci

Устанавливает строго по package-lock.json, не трогает его
Всегда удаляет node_modules перед установкой — чистая среда
Если package-lock.json расходится с package.json — падает с ошибкой
Быстрее в CI/CD за счёт отсутствия resolution-шага

В Dockerfile всегда используй npm ci — получаешь воспроизводимые сборки и гарантию что образ собран ровно с теми версиями, что зафиксированы в локе.
