# Способы создания проекта

## 1. Create Vue (официальный способ для Vue 3)

npm create vue@latest

• Создаётся проект с интерфейсом выбора опций через командную оболочку.  
• Для сборки используется Vite.  
• Можно сразу выбрать TypeScript, Router, Pinia, ESLint и тесты.  

Рекомендация: лучший вариант для новых проектов на Vue 3, если хочешь сразу современную структуру с готовыми опциями.

---

## 2. Vue CLI

npm install -g @vue/cli  
vue create my-project

• Использует Webpack под капотом.  
• Можно выбирать Babel, TypeScript, Vuex, Router, ESLint, Unit/E2E тесты.  
• Исторически Vue CLI для Vue 2, поддержка Vue 3 есть, но менее современная.  

Рекомендация: подходит для существующих проектов на Vue 2 или когда нужен Webpack.

---

## 3. Vite напрямую

npm create vite@latest

• Почти то же, что create-vue, но без встроенного выбора Pinia и Router.  
• Их нужно устанавливать и настраивать отдельно.  
• Dev-сервер быстрый, HMR мгновенный.  

Рекомендация: удобный вариант для тех, кто хочет настроить проект вручную, без готовых опций.

---

## 4. Установка через npm/yarn/pnpm в существующий проект

npm install vue

• Подходит для интеграции Vue в существующие проекты.  
• Используются ES-модули (import { createApp } from 'vue').  
• Требуется сборщик (Vite/Webpack) для полноценной работы с SFC, Router, Pinia.  

Рекомендация: используйте для добавления Vue в существующие приложения или небольшие виджеты с модульной структурой.

---

## 5. Подключение через CDN (скрипт в HTML)

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>

• Для быстрых экспериментов и обучения, маленьких виджетов.  
• Не поддерживает модульную структуру и TypeScript.  

Рекомендация: отлично для экспериментов, учебных проектов или маленьких вставок Vue в статический сайт.

# Экземпляр приложения

Для запуска приложения требуются: html файл с корневым дивом, корневой компонент.  

Каждое приложение требует наличия «корневого компонента», который может содержать другие компоненты в качестве своих дочерних элементов.  

Экземпляр приложения создается с помощью функции createApp(rootComponent, options)  

Одновременно можно создавать несколько экземпляров приложения, которые будут независимы друг от друга.  

Экземпляр приложения не будет ничего отрисовывать, пока не вызвать его метод .mount(), он монтирует приложение в переданный в него селектор дом дерева.  

Метод .mount() следует всегда вызывать после выполнения всех конфигураций приложения и регистрации необходимых ресурсов.

# Реактивность

Для объявления реактивного состояния примитивов в composition api используется ref(), принимает аргумент и возвращает его завёрнутым в объект ref со свойством .value (используется для примитивов: чисел, строк, булевых значений, но ничего не мешает передать туда объект, доступ к нему будет также через .value, с глубокой вложенностью тоже будет все нормально)

Примитивы (number, string, boolean) нельзя сделать реактивными напрямую, потому что они не являются объектами. ref решает это, храня значение внутри объекта.

В шаблоне .value автоматически разворачивается (разворачивание ссылок в шаблонах применяется только в том случае, если ref является свойством верхнего уровня, а не каким то вложенным(test.id)).

Для объявления реактивного состояния объектов в composition api используется reactive()  

Принимает аргумент, возвращает прокси (используется для объектов, массивов, сложных структур данных).

Для исключения глубокой вложенности используются shallowRef и shallowReactive

# Computed

Computed(get(), ?debuggerOptions) — это кэшируемое реактивное значение, которое:

• зависит от других реактивных источников (ref, reactive, props)  
• автоматически пересчитывается только при изменении зависимостей  
• используется как read-only ref (по умолчанию)  
• не следует использовать для некэшируемых данных для них использовать методы  

Принимает геттер функцию и возвращает иммутабельный (доступен только для чтения) реактивный ref-объект для возвращаемого значения из геттера.  

Также можно вернуть объект, используя функции get и set для создания ref-объекта с возможностью записи.

Синтаксис с сеттером если нужно изменять значение (используется редко в основном с v-model)

const value = computed({
  get() { ... },
  set(newValue) { ... }
})
