WebSocket — протокол прикладного уровня, обеспечивающий двусторонний обмен сообщениями между клиентом и сервером. Работает поверх одного TCP-соединения.
Для установки соединения клиент отправляет HTTP Upgrade-запрос для переключения HTTP-протокола на WebSocket. Это требование браузерного Web API; в общем случае (например, при взаимодействии backend-backend) WebSocket может быть реализован поверх другого транспорта.
После HTTP-handshake происходит согласование соединения, и начинается обмен WebSocket-фреймами.
WebSocket использует модель обмена данными через кадры (frames), представляющие собой фрагменты сообщения в бинарном формате.
Соединение может быть установлено по протоколам:
ws:// — незащищённое соединение
wss:// — WebSocket поверх TLS, где данные шифруются транспортным уровнем (аналогично HTTPS для HTTP)
